<h2>Приложение Composition (Сумма чисел)</h2>
<div class="content">
В приложении реализованы следующие возможности:
    <ul>
        <li>выбор уровня сложности игры;</li>
        <li>режим игры, в котором за ограниченное время необходимо набрать необходимое количество очков;</li>
        <li>итоги (фрагмент) в котором отражены результаты, процент правильных ответов и т.д.</li>
    </ul>
Использованы  библиотеки и плагины:
    <ul>
        <li>Dependencies («androidx.navigation:navigation-fragment-ktx»);</li>
        <li>Plugins («ikotlin-parcelize», «androidx.navigation.safeargs», «kotlin-kapt»).</li>
    </ul>
